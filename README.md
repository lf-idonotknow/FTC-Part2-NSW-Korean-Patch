> 전체 엔딩 플레이 검수는 계속 진행 중입니다.

## 다운로드

GitHub의 **Releases**에서 최신 `FTC02_Korean_LayeredFS.zip`을 내려받습니다. 무결성을 확인하려면 같은 릴리스의 `SHA256SUMS.txt`를 이용할 수 있습니다.

## Nintendo Switch·Atmosphère 적용

1. `FTC02_Korean_LayeredFS.zip`의 압축을 풉니다.
2. 압축을 풀어 나온 `atmosphere` 폴더를 SD 카드 최상위에 복사합니다.
3. 기존 패치가 있으면 같은 경로의 파일을 덮어씁니다. 저장 데이터는 패치 폴더와 별개이므로 삭제하지 않습니다.
4. 다음 경로 바로 아래에 `romfs` 내용이 들어 있는지 확인합니다.

   ```text
   /atmosphere/contents/010078400f7b0000/romfs/
   ```

5. 게임이 실행 중이었다면 홈 메뉴에서 완전히 종료한 뒤 다시 실행합니다. 본체를 재부팅할 필요는 없습니다.

패치가 적용되지 않으면 타이틀 ID와 게임 버전이 맞는지, `romfs/romfs`처럼 폴더가 이중으로 들어가지 않았는지 확인해 주십시오.

## Eden·Yuzu 계열 에뮬레이터 적용

1. ZIP에서 다음 폴더를 찾습니다.

   ```text
   atmosphere/contents/010078400f7b0000/romfs
   ```

2. 에뮬레이터에서 해당 게임의 모드 데이터 폴더를 엽니다.
3. `FTC02 Korean Patch` 같은 별도 모드 폴더를 만들고, 그 안에 ZIP의 `romfs` 폴더를 복사합니다.

   ```text
   <에뮬레이터 사용자 폴더>/load/010078400F7B0000/
   └─ FTC02 Korean Patch/
      └─ romfs/
         └─ ...
   ```

4. 게임별 모드 설정에서 패치가 활성화되어 있는지 확인합니다.
5. 게임과 에뮬레이터를 완전히 종료한 뒤 다시 실행합니다.

에뮬레이터마다 모드 폴더의 상위 구조와 메뉴 이름은 다를 수 있습니다. 핵심은 ZIP의 `romfs` 내용이 대상 게임의 교체 RomFS로 읽히도록 배치하는 것입니다.
