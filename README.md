# 패미컴 탐정 클럽: 뒤에 선 소녀 한국어 패치

Nintendo Switch판 「패미컴 탐정 클럽: 뒤에 선 소녀」 일본판/아시아판
Application v0용 비공식 한국어 패치입니다.

> 현재 배포 단계: `v0.6.0-beta`
>
> 정적 빌드 검증은 완료했지만 전체 실기 플레이 검수는 진행 중입니다.

## 적용 대상

| 항목 | 값 |
|---|---|
| 게임 | 패미컴 탐정 클럽: 뒤에 선 소녀 |
| 플랫폼 | Nintendo Switch |
| 기반 언어 | 일본어 |
| 대상 버전 | Application v0 / 게임 표시 1.0.0 |
| 타이틀 ID | `010078400F7B0000` |
| 패치 형식 | Atmosphère LayeredFS |

## 다운로드

GitHub의 **Releases**에서 최신 릴리스의 다음 파일을 받습니다.

- 일반 사용자: `FTC02_Korean_LayeredFS.zip`
- 해시 확인: `SHA256SUMS.txt`

저장소에 보이는 `release` 폴더의 파일은 다음 GitHub Release를 만들 때
사용하는 검증된 원본입니다.

## 설치

1. `FTC02_Korean_LayeredFS.zip`의 압축을 풉니다.
2. 안의 `atmosphere` 폴더를 SD 카드 최상위에 합칩니다.
3. 최종 경로가 다음 형태인지 확인합니다.

```text
/atmosphere/contents/010078400f7b0000/romfs/
```

4. 게임이 실행 중이었다면 완전히 종료한 뒤 다시 실행합니다.

## 에뮬레이터 적용

에뮬레이터에서는 ZIP의 `atmosphere` 폴더를 그대로 설치하지 않고,
그 안에 있는 다음 패치 `romfs`를 에뮬레이터의 게임별 모드 폴더에
배치합니다.

```text
FTC02_Korean_LayeredFS.zip
└─ atmosphere
   └─ contents
      └─ 010078400f7b0000
         └─ romfs
```

### Eden 및 Yuzu 계열

1. 에뮬레이터에서 게임의 모드 데이터 폴더를 엽니다.
2. 타이틀 ID `010078400F7B0000` 아래에 패치 이름의 폴더를 하나
   만듭니다.
3. ZIP에서 꺼낸 `romfs` 폴더를 그 안에 복사합니다.

최종 구조는 다음과 같아야 합니다.

```text
<에뮬레이터 사용자 폴더>
└─ load
   └─ 010078400F7B0000
      └─ FTC02 Korean Patch
         └─ romfs
            └─ ...
```

Eden v0.2.1에서는 위 구조로 게임 부팅과 타이틀 화면의 한국어 표시를
확인했습니다. `romfs` 아래에 다시 `romfs`가 들어가거나,
`FTC02 Korean Patch` 아래에 `atmosphere`가 들어가면 패치가
적용되지 않습니다.

### 다른 Nintendo Switch 에뮬레이터

게임을 오른쪽 클릭해 `Open Mods Directory`, `Open Mod Data Location`
등의 게임별 모드 폴더 열기 기능을 사용합니다. 에뮬레이터마다 모드
폴더의 상위 구조와 메뉴 이름이 다르므로, 해당 에뮬레이터의 LayeredFS
또는 RomFS 모드 설치 방식을 따르되 ZIP 안의 `romfs` 내용이 대상 게임의
교체 RomFS로 읽히도록 배치해야 합니다.

패치를 적용하거나 갱신한 뒤에는 게임과 에뮬레이터를 완전히 종료했다가
다시 실행하십시오. 패치가 보이지 않으면 다음 항목을 확인하십시오.

- 대상 게임의 타이틀 ID가 `010078400F7B0000`인지
- 게임 표시 버전이 `1.0.0`인지
- 게임별 설정에서 해당 모드가 활성화되어 있는지
- 폴더가 `romfs/romfs`처럼 이중으로 들어가지 않았는지

게임 본체, 키와 펌웨어는 사용자가 적법하게 준비해야 하며 이 패치에는
포함되어 있지 않습니다. Eden v0.2.1 이외의 에뮬레이터는 현재
공식 검증 대상에 포함되지 않습니다.

## 제거

다음 폴더를 제거하거나 다른 이름으로 옮기면 패치가 비활성화됩니다.

```text
/atmosphere/contents/010078400f7b0000/
```

저장 데이터는 이 폴더에 포함되지 않습니다.

## 포함 범위

- 번역 MSB 20개와 SCX 1개
- 화면 조사 명칭 INF 111개·538필드
- 독립 생성 한글 글꼴 아틀라스 3개
- 시스템 UI 10개
- 제1장~제11장 장 제목 11개와 픽션 고지 1개
- 장소 표시 애니메이션 22개와 16번 전용 atlas 1개
- 정적 타이틀 화면 1개와 타이틀 애니메이션 1개
- 총 런타임 파일 182개

한국어 키보드 자산은 포함하지 않습니다.

## 문제 보고

Issues의 버그 보고 양식을 사용해 다음 정보를 적어 주십시오.

- 게임 버전과 타이틀 ID
- 사용 환경(실기 또는 에뮬레이터)
- 장·장면과 직전 행동
- 실제 표시와 기대한 표시
- 가능하면 스크린샷

NSP, XCI, NCA, `prod.keys`, 저장 데이터나 원본 게임 파일은 첨부하지
마십시오.

## 권리와 고지

이 프로젝트는 비공식 팬 번역이며 Nintendo의 승인·후원·제휴를 받지
않았습니다. 게임과 관련 상표의 권리는 각 권리자에게 있습니다.

패치에서 사용한 공개 글꼴의 저작권 고지와 OFL 1.1 전문은 각 배포 ZIP
안의 `licenses` 폴더 및 저장소의 `THIRD_PARTY_LICENSES` 폴더에
있습니다. 프로젝트 자체 코드·문서의 공개 라이선스는 아직 지정하지
않았습니다.
