# 글꼴 저작권 및 출처 고지

이 프로젝트는 사라진 후계자 한국어 패치의 완성 이미지 파일을 복사하지
않습니다. 아래 공식 글꼴 파일과 자체 렌더 프로필을 사용하여 뒤에 선
소녀용 글꼴 아틀라스와 UI 텍스트를 새로 생성합니다.

모든 글꼴은 SIL Open Font License 1.1에 따라 사용합니다. 라이선스 전문은
배포물의 `licenses/OFL-1.1.txt`에 포함합니다.

- 사용 파일: `NanumMyeongjoExtraBold.otf`
- 내부 버전: `3.010`

## 파생 자산 명칭

생성된 게임용 PNG 아틀라스는 원 글꼴 제품과 구분하기 위해
`FTC02 Korean Font Atlas`로 지칭합니다. 예약 글꼴명을 파생 글꼴의
제품명으로 사용하지 않습니다.
